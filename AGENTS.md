# Repository Instructions

## Communication

- Respond concisely in Japanese.
- Prefer facts, file paths, command results, and concrete failure modes.
- If an assumption is needed, label it as `Assumption:`.
- For question-only turns, do not edit files or mutate workspace state.

## Project Context

This repository is a Google Apps Script Web App for the ハヤトの野望DB dashboard.

- Apps Script source is under `app/`.
- `doGet()` returns `index.html`.
- `styles.html` is included as an HTML file.
- Browser JavaScript is generated by `include('scripts')` in `code.gs`.
- There is no external frontend build step.

## Browser JavaScript Structure

Keep the GAS-only partial structure.

- Browser JS partials live in `app/scripts_*.html`.
- Partial load order is defined only in `SCRIPT_PARTIALS` in `app/code.gs`.
- Do not reintroduce `app/scripts.html`; `include('scripts')` is virtual and handled by `code.gs`.
- Each `scripts_*.html` file must use this wrapper:

```html
<script type="application/json" data-dashboard-script-partial>
  // JS body
</script>
```

Reason:

- Apps Script HTML template evaluation escapes `<` inside script contexts.
- `code.gs` reads each partial as raw HTML, extracts the wrapper body, base64 encodes the combined module source, and injects it as `<script type="module">` in the browser.
- This preserves copy-paste reproducibility in the Apps Script editor without a local build step.

## Editing Rules

- Keep changes minimal and local.
- Do not introduce external build tooling.
- Do not move client JS into `.gs` template strings.
- Do not add backward-compat shims unless they are free and do not increase branching.
- Prefer readable boring code over abstractions.
- If adding or removing a `scripts_*.html` file, update `SCRIPT_PARTIALS` and run validation.

## Validation

Run before finishing changes:

```bash
rtk node ../tools/validate-ui-contract.mjs
rtk git diff --check
```

Run from `app/` for the UI contract command:

```bash
cd app
rtk node ../tools/validate-ui-contract.mjs
```

The UI contract validates:

- `index.html` includes `styles` and virtual `scripts`.
- Required UI ids/classes/data attributes exist.
- `SCRIPT_PARTIALS` matches `scripts_*.html`.
- JS partial wrappers are valid.
- Expanded module JS has no unexpanded template directives.
- Expanded module JS has no escaped operators such as `&lt;=`.
- Expanded module JS is syntactically valid.

## Deploy

Only deploy when the user asks to reflect changes in the Apps Script Web App.

```bash
cd app
rtk npm run gas:release
```

After deploy, verify the public URL if the change affects browser JS:

- Fetch the Web App URL.
- Decode the base64 module loader.
- Run a syntax check on the decoded module source.
